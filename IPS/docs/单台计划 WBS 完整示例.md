# 起落架大修车间令号·单台计划WBS完整示例
## 前置业务依据（取自两份业务文档）
1. 1个**车间令号**对应1套**单台计划**，单台计划的结构化载体为**WBS**；
2. WBS底层最小节点绑定**工卡任务**，工卡1:1对应实例工序，工序源自BOP实例（维修方案DAG工艺流程）；
3. 车间20个区站：接收/分解站、粗洗、清洗、故检、修理、装配、试验、异常区；
4. WBS层级逻辑：项目阶段→专业作业包→工位作业分组→底层工卡任务（可直接映射BOP工序）；
5. 业务链路：车间令号→大修修理方式→标准BOP方案→实例化工序/工卡→工卡任务归集进WBS。

## 一、WBS整体编码规则
- 顶层：LG-OVHL-001（主起落架大修令号，1级）
- 2级：阶段大类 01/02/03…
- 3级：专业/工位作业包 01.01/01.02…
- 4级：细分作业分组 01.01.01…
- 5级：底层最小工作包=**工卡任务**，直接关联BOP实例工序、排产工位、齐套规则
> 5级节点为排产最小单元，对接智能排产模块「待生效/待接受/修理中/挂起」状态机

## 三、WBS与BOP、智能排产模块映射关系（贴合文档定义）
### 1. 层级对应关系
| WBS层级 | 对象 | 对应业务对象 | 排产模块作用 |
|--------|------|-------------|-------------|
| 1级 | LG-OVHL-001 | 车间令号/单台计划 | 整体交付周期、总里程碑管控 |
| 2级 | 作业阶段 | BOP顶层工序分组（分解/清洗/检测/装配/试验） | 阶段甘特图、阶段负荷汇总 |
| 3级 | 专业作业包 | BOP同工位工序集合 | 区站产能统计、班组任务归集 |
| 4级 | 细分作业分组 | 同类型工序聚类 | 人工批量调整预排时段 |
| 5级 | 底层工作包（最小节点） | 工卡任务 ↔ 实例工序 ↔ BOP标准工序 | 智能排产最小单元，驱动状态机：待生效/待接受/修理中/齐套挂起/负荷挂起 |

### 2. 核心业务映射规则（取自文档标准化定义）
1. **一对多**：1个WBS 4级/3级节点 = 多条BOP工序聚合；
2. **一对一**：1条BOP实例工序 → 1张工卡 → 1条5级WBS工卡任务；
3. **DAG约束落地**：WBS底层工卡任务继承BOP工序DAG前后置关系，排产引擎识别Head节点，禁止后置工卡提前生效；
4. **齐套属性挂载**：5级WBS节点标记「齐套性工卡/非齐套工卡」，排产引擎自动校验物料、委外件到位状态；
5. **非例行工卡独立WBS分支**：1.09异常返工分支，支持高优先级Insert/Recall插队排产。

## 五、适配智能排产模块的WBS设计亮点
1. **工位绑定字段**：每个5级WBS节点携带`station`工位信息，引擎自动归集对应工位管道负荷；
2. **齐套标记`is_material_bundle`**：区分齐套/非齐套工卡，自动触发挂起、重启逻辑；
3. **例行/非例行标记`is_routine`**：异常返工WBS分支标记为false，支持Insert插队；
4. **双关联主键**：每个底层WBS绑定`bop_op_id`（工序）、`workcard_id`（工卡），实现WBS计划层与BOP工艺层双向追溯；
5. **贴合DAG流转**：WBS节点继承BOP前置约束，排产引擎自动识别可开工Head工卡，杜绝逆序排产。
