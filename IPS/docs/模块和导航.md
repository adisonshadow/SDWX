基于《起落架修理车间智能排产模块 需求分析与功能架构》及配套业务文档，规划一套贴合业务实际、可直接用于系统原型设计的**导航结构**与**页面功能明细**。

> 以下规划完全剥离登录、鉴权、用户组织等非业务内容，聚焦排产核心操作与监控场景，覆盖**计划侧**、**调度侧**、**引擎侧**、**可视化侧**及**分析侧**五大板块。

---

## 一、多级导航结构

```
📋 工作台（首页仪表盘）
├── 排产总览（关键指标卡、风险预警、今日任务）

📋 计划排产
├── 令号投产（投产向导 + 工卡批量生成）
├── 单台计划（WBS 树形展示 + 工卡预排调整）
└── 游离工卡池（待生效工卡列表，批量操作）

📋 工位调度
├── 工位管道（栈式队列视图 + 负荷监控）
├── 工卡状态看板（全状态筛选 + 明细）
├── 齐套管理（齐套校验、挂起/重启、委外跟踪）
└── 非例行工卡（创建、Insert/Recall、影响评估）

📋 排产引擎
├── 引擎运行监控（实时日志、触发记录、手动干预）
└── 排产规则配置（排期参数、容量系数、优先级档位）

📋 排产可视化
├── 令号甘特图（多令号/单台计划进度）
└── 工位负荷图（日负荷柱状/热力图、管道占用）

📋 统计分析
└── 排产效能报告（工时中位数、排产偏差、利用率）
```

> 导航最多三级，保证核心操作路径清晰；异常处理、委外等跨模块功能已内嵌到对应页面中。

## 二、各页面功能明细

### 1. 工作台 – 排产总览
| 功能区域 | 明细内容 |
|---------|----------|
| 关键指标卡 | 今日待生效工卡数、待接受工卡数、修理中工卡数、挂起工卡数（齐套/负荷分列）、超期预警工卡数 |
| 管道负荷速览 | 各工位当前管道占用率（环形图/进度条），突出显示超容工位 |
| 风险预警列表 | 齐套长时挂起（>2天）、负荷挂起、交付里程碑即将逾期 |
| 快捷入口 | 一键进入“令号投产”“非例行插单”“齐套看板” |

---

### 2. 计划排产

#### 2.1 令号投产
| 功能点 | 说明 |
|--------|------|
| 投产向导 | 分步表单：选择工厂令号 → 选择产品/修理方式 → 匹配/选用BOP方案 → 填写计划起止日期 → 确认投产 |
| BOP方案预览 | 向导中预览该方案包含的工序列表、DAG结构、目标工位 |
| 批量生成 | 确认后自动生成所有例行工卡（状态=待生效），并赋予默认计划时段 |
| 投产记录 | 列表展示已投令号，支持重新生成、克隆投产、查看BOP实例 |

#### 2.2 单台计划（WBS）
| 功能点 | 说明 |
|--------|------|
| WBS树形展示 | 按 令号 → 阶段 → 作业包 → 工卡任务 分层展开，与BOP工序双向关联 |
| 预排甘特条 | 每个底层工卡显示其默认计划时段（日期+上/下午），支持拖拽调整（留痕） |
| 工卡详情侧栏 | 点击工卡弹出：工序信息、工时选用值、齐套性标记、DAG前后置、历史中位数 |
| 批量顺延 | 选中一组工卡，按DAG约束批量重算计划时间（如因延期） |
| 工时切换 | 可针对单张工卡切换“标准工时”与“历史中位数”作为排程依据 |

#### 2.3 游离工卡池
| 功能点 | 说明 |
|--------|------|
| 待生效工卡列表 | 表格展示：令号、工卡编号、工序名、目标工位、计划时段、DAG Head标志 |
| 筛选/排序 | 按工位、齐套性、计划临近度、优先级等 |
| 手动生效 | 权限控制下，可手动将某工卡生效为“待接受”并推送工位（绕过引擎） |
| 取消工卡 | 批量取消未生效的工卡（状态→已取消） |

---

### 3. 工位调度

#### 3.1 工位管道
| 功能点 | 说明 |
|--------|------|
| 工位选择器 | 切换查看20个区站中任一工位的管道 |
| 栈式队列卡片 | 按优先级/计划时间排序显示“待接受+待修理+修理中”工卡，状态色标 |
| 管道容量环 | 显示当前占用工时/日负荷×2，剩余容量 |
| 挂起工卡列表 | 该工位下“齐套挂起/负荷挂起”工卡，显示挂起原因、挂起时长，支持手动恢复（需校验） |
| 操作按钮 | 对“待接受”工卡可执行“Recall”调整队列位置（仅限有权限调度员） |

#### 3.2 工卡状态看板
| 功能点 | 说明 |
|--------|------|
| 全状态筛选 | 按 待生效/待接受/待修理/修理中/齐套挂起/负荷挂起/修理结束/已取消 多选筛选 |
| 矩阵视图 | 按工位×状态矩阵展示工卡数量，点击钻取明细 |
| 明细表格 | 展示工卡完整属性：令号、工序、计划时段、实际开始/结束、工人、齐套状态 |
| 批量操作 | 对挂起工卡批量“重启”，对已取消工卡可“恢复”（需审批） |

#### 3.3 齐套管理
| 功能点 | 说明 |
|--------|------|
| 齐套规则配置入口 | 维护齐套校验维度（物料/工装/设备/委外件），按工卡类型绑定 |
| 实时齐套状态 | 展示所有齐套性工卡的齐套满足度（百分比），缺项明细 |
| 缺项追踪 | 列出缺项物料、预计齐套时间、影响工卡清单 |
| 委外件齐套看板 | 展示委外在途件、预计返回时间、依赖该件的工卡列表，委外返回后一键触发“重新接受”更新齐套状态 |
| 挂起/重启日志 | 时间线记录工卡因齐套原因挂起和恢复的每次动作 |

#### 3.4 非例行工卡
| 功能点 | 说明 |
|--------|------|
| 创建非例行工卡 | 填写工序、目标工位、优先级、齐套性标记，可选关联异常返工分支或独立插单 |
| Insert操作 | 指定插入工位管道的具体位置（如第2位），系统自动挤占/顺延低优先级工卡 |
| Recall操作 | 将已生效工卡召回至指定位置，状态保持待接受 |
| 影响评估弹窗 | 执行Insert/Recall前，预览被挤占的工卡列表及顺延后的计划时段，确认后生效 |
| 非例行工卡列表 | 单独标记，支持快速筛选查看 |

---

### 4. 排产引擎

#### 4.1 引擎运行监控
| 功能点 | 说明 |
|--------|------|
| 引擎开关 | 一键启停自动排产引擎（后台连续运行） |
| 实时日志流 | 展示最近触发的事件：生效、挂起、重启、顺延、插队等，含时间戳和触发原因 |
| 手动触发 | 允许手工触发一次全量重算（重新评估所有待生效工卡） |
| 异常告警 | 引擎异常停止、循环冲突等告警展示 |

#### 4.2 排产规则配置
| 功能点 | 说明 |
|--------|------|
| 排期参数 | 是否包含周六（开关）、是否包含周日（默认关闭）、上午/下午班次定义、自动生效前瞻窗口（0.5天单位） |
| 管道容量系数 | 全局默认×2，可针对个别工位单独配置 |
| 优先级档位 | 例行/非例行/紧急插单 权重数值配置 |
| 工时选用优先级 | 标准工时 vs 历史中位数 的优先策略（如样本量>30时优先中位数） |
| 挂起释放管道 | 固定为“释放”，不可关闭（文档已固化） |

---

### 5. 排产可视化

#### 5.1 令号甘特图
| 功能点 | 说明 |
|--------|------|
| 多令号对比 | 选择多个令号，展示其单台计划WBS的工卡条带，按时间轴排列 |
| 状态着色 | 待生效（灰色）、待接受（黄色）、修理中（蓝色）、挂起（红色）、结束（绿色） |
| DAG依赖线 | 可选显示工卡间的强制前置连线（仅显示Head关系） |
| 缩放与滚动 | 支持按天/周/月视图切换，滚动浏览 |

#### 5.2 工位负荷图
| 功能点 | 说明 |
|--------|------|
| 日负荷柱状图 | 按工位展示未来7天/14天每个可排工作日的负荷（已占用vs日负荷基准） |
| 管道占用热力图 | 以颜色深浅表示各工位当前管道占用率，快速定位瓶颈 |
| 负荷预测 | 基于待生效工卡计划时段，展示未来负荷趋势，预警超容风险 |

---

### 6. 统计分析 – 排产效能报告
| 功能点 | 说明 |
|--------|------|
| 工时中位数自动更新 | 按 机型×修理方式×工序 统计实际完成时长中位数，展示列表，支持人工修正 |
| 排产偏差分析 | 对比“默认计划时段”与“实际生效时段”、“计划完成”与“实际完成”的偏差均值/最大偏差 |
| 管道利用率 | 各工位历史管道利用率（已占用工时/总容量），区分常态与插单场景 |
| 挂起损耗占比 | 齐套挂起、负荷挂起分别造成的产能损失工时统计 |
| 报表导出 | 支持Excel/PDF导出 |
