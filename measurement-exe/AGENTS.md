# 测量适配程序

Win7 及以上的本机测量适配程序，监听 `3133`，按 IPS 设备测量接口接收任务并在右下角面板展示。任务只放内存。回调地址、处理模式、模拟采集和日志路径会记住，进程重启后仍在。

## 设置

托盘右键「设置」，以及主面板标题栏右侧的齿轮，打开的是同一个设置窗口。标题栏最左边是程序图标，接着是标题，右侧齿轮旁边是减号，用来隐藏面板。

设置项：

- 回调地址。保存后写入程序旁边的 `callback.json`，立刻作为后续提交的回调地址。空着保存时不改原来的地址。
- 处理 API 的模式，二选一，默认覆盖模式。
- 启用开发模拟采集。默认开启。关掉后，主面板不显示「模拟数据」，测试接口返回 `MOCK_DISABLED`。打开时，最下面同一行里「模拟数据」和「清除重测」靠左，「提交测量」靠右。按钮有圆角，宽度只比文字稍长。点「模拟数据」填入各项模拟值。每一项旁边不再单独放采集按钮。
- 主面板最高是屏幕高度的 70%。标题栏和底部按钮固定，中间内容超出时可以滚动。每一项的要求和采集结果在同一行，结果靠右；还没采集时右边显示「未采集」。任务号、测量目标和公称值、上偏差这些标签后面的内容，用浅灰底、轻微圆角的标签显示。
- 标准参数在程序旁边的 `standard-params.json`。设备、参数，以及测量目标、采集项需求的显示名称都在这个文件里。改完后重新启动即可，健康检查里的 `standardRevision` 用文件中的 `version`。编译时会把工程里的这份文件复制到程序旁边。
- 提交后如果测量结果没有送达，任务和已采集的数据都保留，面板显示「返回当前测量」。点回去可以继续看原来的数据并再次提交。超时失败的任务仍会移除。
- 开机自启动。写当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值名 `measurement-adapter`。这一项只在设置里，托盘菜单不再放。
- 日志文件地址。默认是程序旁边的 `measurement-adapter.log`。
- 定位到日志文件。没有文件时先创建，再用资源管理器选中它。

点「保存」后，模式、模拟采集和日志路径写入程序旁边的 `config.json`，键为 `processMode`（`overwrite` 或 `queue`）、`mockCollect`、`logFile`。写入时保留文件里已有的 `alwaysOnTop`、`confirmTimeoutSeconds`。窗口是否置顶仍由托盘菜单切换，不放进这个设置窗口。

测试可以用环境变量 `MEASUREMENT_PROCESS_MODE=queue` 或 `overwrite` 覆盖已保存的模式，且不改 `config.json`。

## 覆盖模式

默认。同一时间只保留一个待处理任务。新的测量请求只要任务号不同，就接受，并丢掉其余还没提交完的任务。被丢掉的任务不回调服务端。正在提交回调的任务不会被丢掉。

同一个还在内存里的任务号仍然返回 `409 TASK_DUPLICATED`。不再因为「该设备已有任务」返回 `DEVICE_BUSY`。不同设备类型也不会同时留着。

## 队列模式

测量请求都会留下，包括同一设备类型的多个任务。新任务到来时，如果操作员已经手动切换过当前任务，面板不抢走当前正在处理的那条；否则显示最新一条。

面板在有多条任务时可以「切换任务」，选择先处理哪一条。队列模式下有「关闭任务」：只有一条时直接确认关闭，有多条时先点选要关的那一条。强制关闭只从本机队列移除，不回调服务端。正在提交的任务不能关。

## 设备检测

设置窗口里的「设备检测」打开检测窗口。它扫描本机已接入的 COM 口、USB 转串口，以及没有串口通道的 USB 设备。串口和 USB 转串口标记为允许采集，协议是 Modbus RTU，可以按原始字节收发。原生 USB 只列出，不允许采集，也不做寄存器解析和测量值换算。

## 日志文件

`GET /api/measurement/logs` 仍是内存里最近 1000 条，不含测量值。同一条短日志会追加到日志文件，同样不写测量值和图片。

## 安装包

`installer/setup.iss` 用 Inno Setup 编译，产物是 `dist/MeasurementAdapter-1.0.0-setup.exe`。安装包要求 Windows 7 SP1 及以上、能运行 64 位程序的系统。安装到 `Program Files\SDWX\测量适配程序`，带开始菜单快捷方式，并放行 TCP 3133 入站。不默认开机自启动。再次安装会更新程序，已有的 `standard-params.json`、`callback.json`、`config.json` 和日志不会被覆盖或删除。
